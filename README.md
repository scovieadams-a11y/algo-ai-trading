# algo-ai-tradingAdams AI Trading Platform 🚀

An AI-powered trading platform designed to provide market analysis, trading signals, demo trading, and portfolio management tools for Forex, Metals, Crypto, and Indices.

📌 Overview

Adams AI Trading is a full-stack trading platform project that combines modern web technologies with trading analysis tools to help traders analyze markets and manage their trading activities.

The platform is being developed with:

- Frontend user interface
- Backend API
- Database management
- AI-based market analysis
- Trading dashboard
- Signal generation system

⚙️ Installation Guide

1. Clone Repository

git clone your-repository-link

2. Enter Backend Folder

cd backend

3. Install Dependencies

npm install

4. Add Environment Variables

Create a ".env" file:

MONGO_URI=your_mongodb_connection_string

5. Start Server

npm start

Server runs on:

http://localhost:5000
